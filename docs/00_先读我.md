# AI 全栈开发环境 · 总入口

> 把 Zig 编译器、ZLS 语言服务器、AI 视觉辅助、实时热重载渲染
> 四套能力整合在一起，**AI 能写代码 → 编译 → 看见结果 → 判断对不对 → 再改** 的完整闭环。
>
> 组装日期：2026-09-16　全部组件均已实测跑通，非拼凑。

## 一、这套东西能干什么

```
    ┌──────────────┐
    │  AI 写代码    │ ← ZLS 实时告诉 AI：这行有错、这个函数有哪些成员
    └──────┬───────┘
           ↓
    ┌──────────────┐
    │  Zig 编译     │ ← 零配置交叉编译，导出表干净
    └──────┬───────┘
           ↓
    ┌──────────────┐
    │  程序渲染     │ ← 改代码 → 重新编译 → 窗口不关，画面自动更新
    └──────┬───────┘
           ↓
    ┌──────────────┐
    │  截图         │
    └──────┬───────┘
           ↓
    ┌──────────────────────────────┐
    │  AI 视觉分析（关键环节）       │
    │  · 这是什么（ResNet50）       │
    │  · 文字对不对（OCR+坐标）      │
    │  · 颜色对不对（精确RGB）       │
    │  · 排版对不对（重叠/超界检测）  │
    └──────┬───────────────────────┘
           ↓
      判断"对不对" → 不对就改 → 回到第一步
```

**核心突破**：AI 不再"盲写"。以前写完代码只能说"应该能行"，
现在能真的看见渲染结果，并**用数据验证颜色、文字、排版是否正确**。

## 三、最快上手（3 分钟）

```bash
# 1. 安装并自检
bash 一键安装.sh

# 2. 启动虚拟屏幕（无显示器环境需要）
Xvfb :99 -screen 0 1280x1024x24 &
export DISPLAY=:99

# 3. 编译并运行
cd 03_热重载渲染工程/项目源码
zig build
export LD_LIBRARY_PATH=../raylib运行时:$LD_LIBRARY_PATH
./zig-out/bin/host &

# 4. 改代码看效果
vim src/game.zig        # 随便改，比如改个颜色
zig build               # 重新编译
# → 窗口不关，画面自动变

# 5. AI 看结果
python3 ../../02_AI视觉辅助/see2.py 截图.png
```

## 四、三个主工具的用法

### 1. `lsp_query.py` —— AI 查代码真相

不打开编辑器，也能拿到编译器级信息。解决"AI 用过时 API"的问题。

```bash
python3 01_Zig与ZLS/lsp_query.py diagnose main.zig        # 查错误
python3 01_Zig与ZLS/lsp_query.py complete main.zig 5 8    # 补全（真有哪些成员）
python3 01_Zig与ZLS/lsp_query.py hover main.zig 3 10      # 查标识符真实类型
python3 01_Zig与ZLS/lsp_query.py symbols main.zig         # 列所有符号
```

**为什么重要**：Zig 0.16 把 `callconv(.C)` 改成了 `.c`。
靠记忆写必错，问 ZLS 才准——它跑的是与编译器同源的分析器。

### 2. `see2.py` —— AI 看图判断

```bash
python3 02_AI视觉辅助/see2.py 图.png                    # 完整五项
python3 02_AI视觉辅助/see2.py 图.png --region 190,210,1091,813  # 只看窗口区域
python3 02_AI视觉辅助/see2.py 图.png --no-ai            # 跳过AI识别（快）
```

输出五项：AI 语义 / OCR 文字+坐标 / 主色 RGB / 排版检测 / ASCII 预览

**实测能力边界**（说实话）：
| 项目 | 准不准 |
|---|---|
| 颜色对不对（精确 RGB） | ✅ 100% 准 |
| 排版对不对（重叠/超界） | ✅ 准 |
| 文字内容（OCR） | ✅ 准（白字深底读不出） |
| "这是什么"（语义） | ⚠️ 只能分 1000 类，认不出具体 UI 元素 |

### 3. `raylib_shot.py` —— 截图

```bash
python3 03_热重载渲染工程/工具/raylib_shot.py ./zig-out/bin/host shot 3 2.0
```
自动启动 Xvfb、运行程序、间隔截图、清理进程。
