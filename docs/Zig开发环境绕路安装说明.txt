【三】ZLS 编译全过程（本次实测，可复现）
────────────────────────────────────────────────────────────────

■ 步骤 1：装 Zig（已有可跳过）
    pip install ziglang -i https://mirrors.cloud.tencent.com/pypi/simple
    → Zig 0.16.0

■ 步骤 2：下载 ZLS 源码（必须与 Zig 版本匹配！）
    # 查可用 tag
    curl -s https://api.github.com/repos/zigtools/zls/tags
    # Zig 0.16.0 → ZLS 0.16.0
    curl -sL -o zls.tar.gz \
      "https://codeload.github.com/zigtools/zls/tar.gz/refs/tags/0.16.0"
    tar xzf zls.tar.gz && cd zls-0.16.0

■ 步骤 3：★ 解决依赖下载被封（关键坑）
    直接 zig build 会报：
        error: bad HTTP response code: '403 Forbidden'
        .url = "https://github.com/ziglibs/known-folders/archive/..."

    原因：Zig 包管理器从 github.com 下载依赖，被封。

    解法：把 build.zig.zon 里的 URL 换成 codeload 格式
        github.com/{owner}/{repo}/archive/{sha}.tar.gz
      → codeload.github.com/{owner}/{repo}/tar.gz/{sha}

    ★ 实测 hash 完全一致，不用改 hash！
      （用 zig fetch 验证过：codeload 返回的 hash 与 .zon 中记录的
        完全相同，说明两者 tarball 内容一致）

    本次替换的 4 个依赖：
        known-folders → codeload.../ziglibs/known-folders/tar.gz/d6d0383...
        diffz         → codeload.../ziglibs/diffz/tar.gz/b39fe07...
        lsp-kit       → codeload.../zigtools/lsp-kit/tar.gz/b886a2b...
        tracy         → codeload.../wolfpld/tracy/tar.gz/refs/tags/v0.13.1

■ 步骤 4：编译
    zig build -Doptimize=ReleaseSafe
    → zig-out/bin/zls (20 MB)  ✅

■ 步骤 5：验证
    zls --version  → 0.16.0

【五】给 AI 用的工具：lsp_query.py（原创）
────────────────────────────────────────────────────────────────

编辑器对人有用，但 AI 需要的是**可编程查询**。
lsp_query.py 让 AI 不打开编辑器也能拿到编译器级信息。

  用法：
    python3 lsp_query.py diagnose 文件.zig          # 查错误
    python3 lsp_query.py hover 文件.zig 3 10        # 查类型
    python3 lsp_query.py complete 文件.zig 5 8      # 补全
    python3 lsp_query.py definition 文件.zig 3 10   # 跳转定义
    python3 lsp_query.py symbols 文件.zig           # 列符号

  环境变量 ZLS_PATH 可指定 zls 位置，默认 /usr/local/bin/zls

  为什么有价值：
    AI 写 Zig 时容易用过时 API（比如 0.16 把 callconv(.C) 改成 .c）。
    与其靠记忆猜，不如问 ZLS —— 它跑的是与编译器同源的分析器。

【八】Windows 用户怎么办（重要）
────────────────────────────────────────────────────────────────

你本机网络不受限，不需要绕路，直接装即可：

■ 最简单（推荐）
    1. 装 VS Code
    2. 扩展里搜 "Zig" (ziglang.vscode-zig) 安装
    3. 插件会自动下载匹配版本的 ZLS
    → 这是官方推荐路径，你本机没有网络限制

■ 手动编译 ZLS（如需最新版）
    git clone https://github.com/zigtools/zls
    cd zls
    zig build -Doptimize=ReleaseSafe
    # 产物 zig-out/bin/zls.exe

■ 版本匹配是硬要求
    ZLS 与 Zig 版本必须对应，否则行为异常。
    Zig 0.16.0 → ZLS 0.16.0


────────────────────────────────────────────────────────────────
【九】本方法的通用价值
────────────────────────────────────────────────────────────────

codeload 可用意味着：**任何 GitHub 开源项目都能拿到源码**。

  拿源码：
    curl -sL -o x.tar.gz \
      "https://codeload.github.com/{owner}/{repo}/tar.gz/refs/tags/{tag}"
    # 或 /refs/heads/{branch}

  列文件（找非LFS的大文件，LFS在tree里只有131字节）：
    curl -s "https://api.github.com/repos/{owner}/{repo}/git/trees/main?recursive=1"

  单文件：
    curl -sL "https://raw.githubusercontent.com/{owner}/{repo}/{branch}/{path}"

  已被验证可获取：
    ✅ zigtools/zls          (Zig语言服务器)
    ✅ ziglang/vscode-zig    (官方VS Code插件)
    ✅ neovim/nvim-lspconfig (nvim LSP配置集合)
    ✅ helix-editor/helix    (2.9MB源码，未编译)
    ✅ microsoft/onnxruntime (上一轮拿的 ResNet50 模型)

  仍不可得：
    ❌ 任何走 GitHub Release 的预编译二进制（在 objects 域）
    ❌ HuggingFace 模型
    ❌ VS Code / JetBrains / Zed 官方下载
